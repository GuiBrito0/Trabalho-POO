# Módulo de Locação Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o cadastro de veículos em uma locadora de verdade: clientes, aluguel, devolução, desconto, multa, CNH e idade mínima.

**Architecture:** Regras de negócio vivem nas entidades (`Veiculo`, `Cliente`, `Locacao`) e em `LocacaoService`. `Locadora` vira só menu e leitura de dados (via `Entrada`), captura `RegraDeNegocioException` e imprime a mensagem. Repositórios seguem o padrão interface + implementação em `ArrayList` que já existe.

**Tech Stack:** Java puro (JDK), sem Maven, sem JUnit. Testes num runner próprio em `Testes/Testes.java`.

**Spec:** `docs/superpowers/specs/2026-11-24-locacao-design.md`

## Global Constraints

- Pacotes (pastas na raiz, com maiúscula, como já existe): `Aplicacao`, `Entidades`, `Servicos`, novos `Excecoes` e `Testes`.
- Compilar: `javac -encoding UTF-8 -d bin Aplicacao/*.java Entidades/*.java Excecoes/*.java Servicos/*.java Testes/*.java` (os fontes têm acentos). Rodar testes: `java -cp bin Testes.Testes`. Rodar app: `java -cp bin Aplicacao.Programa`.
- Valores das regras: desconto 10% do aluguel se dias >= 7; multa = 50% da diária aplicada por dia de atraso, sem desconto; mínimo 1 dia; idade mínima 21 anos na data da retirada; carro exige CNH B ou AB; moto exige A ou AB.
- Ano do veículo entre 1980 e (ano atual + 1). Diária, potência e cilindradas > 0. Categoria de carro: Suv, Sedan, Hatch ou Picape (sem diferenciar maiúsculas).
- Placa única (normalizada: trim + maiúsculas). CPF único (só dígitos, 11).
- Datas `dd/MM/yyyy`; Enter = hoje.
- Mensagens para o usuário em português. Código e comentários no estilo atual do projeto (nomes em português).
- Mensagens de commit terminam com a linha `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Não alterar a estrutura de POO existente (`Veiculo` abstrata, `Carro`/`Moto`, `Motor`, interface `Repositorio`), só estender.

## Review Focus

Entradas que o spec não menciona, mas que uma pessoa usando o programa vai fazer. Cada uma tem teste na tarefa indicada.

1. Texto onde se espera número ("abc" no menu) repete a pergunta em vez de quebrar. (Task 7)
2. Placa digitada em minúsculas ou com espaço ("abc1234 ") encontra o mesmo veículo e não cria duplicata. (Tasks 2 e 5)
3. CPF digitado com pontos e traço é aceito e igual ao CPF só com dígitos. (Tasks 3 e 5)
4. Devolver um veículo que não está alugado, ou devolver duas vezes, dá mensagem de erro e não quebra. (Task 6)
5. Cliente que faz 21 anos exatamente no dia da retirada pode alugar. No dia anterior, não. (Tasks 3 e 6)

Também cobertos: devolução com data anterior à retirada (Task 4) e fim da entrada (Ctrl+D / EOF) encerrando o programa sem erro (Tasks 7 e 8).

### Task 6: LocacaoService

**Files:**

**Interfaces:**
- Consumes: os três repositórios, `Locacao`, `Cliente`, `Veiculo`, exceções.

  - `Locacao alugar(String cpf, String placa, LocalDate retirada, int dias)`: valida nesta ordem e lança `NaoEncontradoException` (cliente, depois veículo), `VeiculoIndisponivelException` (locação aberta), `CnhIncompativelException` (`!veiculo.aceitaCnh(cliente.getCnh())`), `ClienteMenorDeIdadeException` (`cliente.idadeEm(retirada) < 21`); só então cria e registra a `Locacao`.

  - `ArrayList<Veiculo> veiculosDisponiveis()`, `ArrayList<Locacao> locacoesAbertas()`, `ArrayList<Locacao> historicoDoCliente(String cpf)` (`NaoEncontradoException` se o cliente não existe).

### Task 8: Menu (Locadora) e dados de exemplo (Programa)

**Files:**

**Interfaces:**
- Consumes: `LocacaoService`, `Repositorio`, `RepositorioClientes`, `Entrada`, todas as entidades e exceções.
